# Bombs At Sea

A browser-based strategy game where you build a naval empire and attack enemies.

## How to Run

Open `index.html` in a web browser - no server required.

## Game Overview

- Resource management game with food, materials, and gold
- Build production buildings (farms, orchards, mills, gold mines)
- Create military units (ships, tanks, planes)
- Attack enemies and enemy docks for rewards

## File Structure

- `index.html` - Main game page
- `game.js` - Game logic and state management
- `style.css` - Styling
- Various `.png` files - Game assets and sprites

## Testing

Manual testing via browser - click through building/attacking functionality.
